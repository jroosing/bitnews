# Vendored browser assets

Everything here is served by the daemon itself (no CDN, no remote fonts).
`scripts/vendor-web.sh` downloads each package from the npm registry,
verifies the sha512 integrity string npm publishes for the tarball (pinned in
the script) and copies the file. Bump a version by editing the script and the
template (`assets/templates/head.html`), then record it here.

Alpine is the **CSP build**: the normal build evaluates expressions with
`new Function`, which needs `'unsafe-eval'`. The CSP build interprets a large
subset of JavaScript expressions itself.

Tailwind CSS 4.3.3 is a build tool, not an asset: see `scripts/get-tailwind.sh`
(SHA-256 pinned) and `internal/web/README.md`.
